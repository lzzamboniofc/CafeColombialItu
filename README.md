# Café Colômbia Itu

Site institucional responsivo do Café Colômbia Itu, preparado como projeto Node.js com Vite.

## Executar localmente

```bash
npm install
npm run dev
```

## Gerar versão de produção

```bash
npm run build
npm run preview
```

O build é gerado na pasta `dist`.

## GitHub Pages

O projeto mantém `index.html` e os arquivos públicos na raiz do repositório para continuar compatível com a configuração:

- Branch: `main`
- Pasta: `/root`

O site funciona diretamente pelo GitHub Pages e também pelo fluxo Node/Vite.

## Estrutura

- `index.html`: página principal
- `src/main.js`: entrada do Vite
- `assets/css/style.css`: identidade visual e responsividade
- `assets/js/main.js`: interações existentes do site
- `assets/images/`: imagens do projeto
- `vite.config.js`: configuração do Vite

## Antes de publicar

- Confirmar o endereço: fontes públicas divergem entre Rua Santa Rita, 1752 e 1779.
- Confirmar o horário completo de sábado.
- Confirmar se o telefone `(11) 2429-3917` também recebe WhatsApp.
- Substituir os itens ilustrativos do cardápio por cardápio e preços oficiais.
- Obter aprovação para uso das imagens e textos finais.
